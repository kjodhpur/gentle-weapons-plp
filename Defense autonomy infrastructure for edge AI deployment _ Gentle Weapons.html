GWOS

A Linux distribution purpose-built to run AI workloads in production.

GWOS takes the Nvidia Jetson family of compute from developer kit to fielded, attestable compute. Immutable rootfs, A/B updates, signed OTA, kernel-locked CUDA, built for reliability. The things you'd expect from a production OS, but tuned for autonomy payloads in a sealed enclosure.

  • [ OK ]TPM-backed boot, secure-element device identity, SBOM per image
  • [ OK ]FIPS 140-3 cryptographic track, CMMC L2 alignment roadmap

Poolnet

An edge-first private mesh. Self-forming, encrypted, egress-optional.

Poolnet is what your autonomy fleet talks over when the LTE is jammed, the satcom is politely degraded, and the TAK server is three valleys away. A next-generation overlay that discovers peers, heals partitions, and lets you reach any node from an operator laptop, a co-deployed drone, or a rack at home through untrusted network space.

> CAPABILITY_SET
  • [ OK ]Quantum-safe encrypted links · per-node keypairs · short-lived certs
  • [ OK ]Partition-tolerant · continues operating without backhaul
  • [ OK ]Policy-driven egress · optionally tethered to cloud
  • [ OK ]Operator-in-the-loop ACLs · audit trail · time-boxed access

Poolboy

A deployment system for next-gen AI workloads on autonomous platforms.

Poolboy delivers modern devops capabilities for shipping models and binaries to robots, UAS, and ground vehicles already in test and field-deployed scenarios. Canary to a single host, widen to a wave, confirm per-node signatures, and roll back when regressions happen. Works over Poolnet. Lands on GWOS. Treats every rollout like the live operation it is.

> CAPABILITY_SET
  • [ OK ]Fleet-scale rollouts · canary / wave / region targeting
  • [ OK ]Cryptographically signed, per-node acknowledged deploys
  • [ OK ]Atomic rollback to last-known-good on telemetry breach
  • [ OK ]Bandwidth-aware · resumable · works over intermittent links
  • [ OK ]Human-authorized go/no-go gates · multi-operator control
