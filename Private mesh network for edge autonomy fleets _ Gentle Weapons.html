Mesh network

A mesh network for autonomous systems must keep working when LTE is jammed, satcom degrades, and backhaul disappears. Buyers evaluating drone mesh network options—Meshmerize, Mobilicom, ZeroTier, BSS Holland, and similar—need encrypted peer links, partition healing, and operator reach without assuming a stable cloud anchor. Poolnet is an edge-first private mesh: self-forming, encrypted, egress-optional overlay built for defense autonomy fleets operating in disconnected, degraded, intermittent, and limited environments.

Mesh that survives EW and geography

Cloud-trained autonomy has no path home when the link dies. Poolnet discovers peers, routes around partitions, and lets operators reach any node from a co-deployed asset, a laptop at the edge, or a tethered egress when policy allows.

  • [ OK ]Operator-in-the-loop ACLs and audit trails

Interlocks with rollout and OS

Poolnet carries signed manifests from Poolboy to GWOS nodes across the same mesh—deployment and connectivity share one contested-edge assumptions.
